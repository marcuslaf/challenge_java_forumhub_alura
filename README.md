# ForumHub - REST API for Discussion Forum

**API REST completa para gerenciamento de fórum de discussões desenvolvida com Spring Boot. CRUD de tópicos, autenticação JWT, autorização por roles (USER, ADMIN, MODERATOR), migrations Flyway e documentação Swagger.**

**Complete REST API for discussion forum management built with Spring Boot. Topic CRUD, JWT authentication, role-based authorization (USER, ADMIN, MODERATOR), Flyway migrations, and Swagger documentation.**
